# 8.4 — Paquete de Windows y prueba en un Windows limpio

> Fase 8. Depende de 8.2 y 8.3. Decisión D15 (publicar sin firma de código).

## 1. Objetivo y «Hecho cuando»

**Objetivo:** un `.zip` de Windows que alguien sin conocimientos pueda descargar, abrir y usar.

**Hecho cuando** (es el «Hecho cuando» de la Fase 8): una persona descarga `GameMolde-<versión>-windows.zip` en un Windows que nunca tuvo Godot, crea un personaje y exporta un `.glb` que pasa `probar_glb.gd`.

## 2. Nivel de modelo

**Simple.** Es el gemelo del 7.4 con dos añadidos: el aviso de SmartScreen y la prueba en limpio.

## 3. Contexto mínimo

- `ruta/pasos/7.4_release.md`, §5.
- `ruta/pasos/8.2_build_windows.md`, §5 y §7.
- `README.md`, sección «Descargar y abrir».

## 4. Archivos

- **Se toca:** `pruebas/fase_7/empaquetar.sh` (segundo argumento: plataforma), `README.md` (apartado de Windows).
- **No se toca:** código.

## 5. Diseño

1. **`empaquetar.sh <versión> <linux|windows>`:** para `windows`, copia `gamemolde.exe`, `LICENSE`, `CREDITOS.md` y `LEEME.md`. **No** incluye `gamemolde.console.exe` ni `autoprueba.bat`: son para pruebas. Nombre: `GameMolde-<versión>-windows.zip` y su `.sha256`.
2. **README, apartado «Windows»** (texto exacto propuesto):
   > 1. Descarga `GameMolde-…-windows.zip` y descomprímelo (botón derecho → «Extraer todo»). No lo abras desde dentro del `.zip`.
   > 2. Haz doble clic en `gamemolde.exe`.
   > 3. La primera vez, Windows puede mostrar «Windows protegió su PC». Es porque el programa no está firmado (firmarlo cuesta dinero cada año). Pulsa «Más información» y después «Ejecutar de todas formas».
   > 4. Necesitas una tarjeta gráfica con Vulkan (casi todas las de 2016 en adelante) y Windows 10 o 11 de 64 bits.
   > Si quieres comprobar que el archivo es el original, compara su `sha256` con el publicado.
3. **Prueba en limpio.** Opciones, de mejor a peor:
   - **Windows Sandbox** (viene con Windows 10/11 Pro; se activa en «Características de Windows»): un Windows vacío que se borra al cerrarlo. Aviso: su tarjeta gráfica virtual puede no tener Vulkan (**NO VERIFICADO**); si el programa no abre ahí, no es concluyente.
   - Otro PC o una cuenta de usuario nueva en el mismo PC (comprueba rutas y permisos, no la falta de bibliotecas).
   - La máquina de un amigo: es la prueba real del «Hecho cuando».
4. **Qué mirar en la prueba en limpio** (lista para el responsable):
   - ¿Se abre sin pedir instalar nada (ni «VCRUNTIME», ni «Vulkan»)?
   - Tiempo desde el doble clic hasta ver el maniquí (cronómetro). Presupuesto: `RENDIMIENTO.md` §2.
   - Mover 3 deslizadores, Deshacer, exportar al Escritorio.
   - Llevar el `.glb` a Linux y pasar `probar_glb.gd`.
5. **Publicar:** el responsable añade el `.zip` a la versión de GitHub (`gh release upload v0.1.0 build/GameMolde-0.1.0-windows.zip build/GameMolde-0.1.0-windows.zip.sha256`) o saca la 0.1.1.
6. **Mejoras que se apuntan y no se hacen aquí** (propuestas para `IDEAS.md`): icono propio en el `.exe` (`rcedit` + Wine), instalador, firma de código.

## 6. Prueba

| Comprobación | Límite |
| --- | --- |
| Contenido del `.zip` | Exactamente 4 archivos |
| `sha256sum -c` del `.zip` | `OK` |
| Descomprimido en una carpeta con espacios y tilde (`C:\Users\…\Descargas\Mi prueba ñ\`), el programa abre y exporta | Sí |
| `.glb` exportado en el Windows limpio con `probar_glb.gd` | `TODO BIEN` |
| Tiempo de arranque en el Windows limpio | Se anota (PROVISIONAL: ≤ 5 s el primer arranque, por el antivirus; ≤ 3 s los siguientes) |
| `probar_readme.sh` | Pasa, con la cadena nueva `SmartScreen` añadida a su lista |

**Que la prueba detecta el fallo:** empaquetar el `.exe` exportado **sin** «Incrustar PCK» (queda un `.pck` suelto que no se copia) → el programa no encuentra sus datos al abrirlo. Volver a activar la opción.

## 7. Trampas conocidas

- Abrir el `.exe` desde dentro del `.zip` (sin extraer) lo ejecuta desde una carpeta temporal de solo lectura: puede fallar al guardar. Por eso el README dice «extraer».
- Un archivo descargado lleva la «marca de la web»; SmartScreen sale solo en el primer arranque.
- Algunos antivirus marcan como sospechoso cualquier `.exe` nuevo sin firma. No se puede evitar sin firma; el `sha256` publicado es la defensa.
- No prometas en el README una versión mínima de Windows más baja que la que soporta Godot 4.7 (**NO VERIFICADO**: comprobar en su documentación antes de escribir «Windows 10»).

## 9. Si te atascas

- Si en el Windows limpio no abre y no hay mensaje: lanzar `gamemolde.console.exe` desde `cmd` y copiar lo que imprima. Para ahí.
- Si pide una biblioteca (`.dll`) que falta: no la copies de otra máquina al paquete. Anota el nombre y pregunta.

# 4.7 — Panel Acabado y preset versión 2

> Paso del MVP. Depende del 4.4. Lee antes `A4_estado_y_migraciones.md`. Decisiones: D7, D8, D9 y D27.
> Subpasos: **4.7a** núcleo (material + preset v2), **4.7b** panel, **4.7c** guardar y abrir preset desde la ventana (solo si se aprueba D27).

## 1. Objetivo y «Hecho cuando»

**Objetivo:** cambiar desde la ventana el color de piel, el borde de la sombra, la luz de contorno (fuerza y ancho) y el grosor del contorno, y que esos valores viajen en el preset.

**Hecho cuando:**
- El panel Acabado cambia el maniquí en vivo y cada cambio se puede deshacer.
- `Preset` escribe la versión 2 (con `acabado`) y abre un preset v1 con el mismo resultado de antes más el acabado por defecto.
- Un preset con `"version": 3` se rechaza con un mensaje que dice que hay que actualizar el programa.
- `probar_presets.gd`, `probar_material.gd` y `probar_acabado.gd` pasan; el resto de pruebas, igual que antes.

## 2. Nivel de modelo

**Medio.** Cambia un formato con archivos ya guardados y una firma que usan varias pruebas. 4.7b es **simple** una vez hecho 4.7a.

## 5. Diseño

### 4.7a — Núcleo

```gdscript
# godot/addons/creador/body_material.gd
## Valores del acabado que se pueden cambiar: nombre → [mínimo, máximo]. Los rangos son los hint_range de los shaders.
const FINISH := {"softness": [0.0, 0.5], "rim_strength": [0.0, 1.0], "rim_width": [0.0, 1.0],
    "mid_shade": [0.0, 1.0], "shadow_shade": [0.0, 1.0], "width_px": [0.0, 10.0]}

## Recorta al rango. false (y no cambia nada) si el nombre no está en FINISH o el valor es NaN o infinito.
static func set_finish(mesh: MeshInstance3D, name: String, value: float) -> bool
static func get_finish(mesh: MeshInstance3D, name: String) -> float
## {nombre: valor por defecto} de los 6.
static func finish_defaults() -> Dictionary
```

- `width_px` va al material del contorno: `set_finish` llama a `set_outline_width` y `get_finish` a `get_outline_width` (ya existen). Los otros 5: `set_shader_parameter` sobre `mesh.material_override`, y `_parameter()` para leer.
- `finish_defaults()`: los 5 de `DEFAULTS` más `OUTLINE_DEFAULTS["width_px"]`.

```gdscript
# godot/addons/creador/preset.gd
const VERSION := 2
const FIELDS := ["version", "especie", "nombre", "valores", "colores", "acabado", "prenda_visible"]

static func to_dict(preset_name: String, species_id: String, values: Dictionary, colors: Dictionary,
        garment_visible: bool, finish := {}) -> Dictionary
static func migrate(data: Dictionary) -> Dictionary      # {"error": "", "data": Dictionary}; ver A4 §5.2
static func _v1_to_v2(data: Dictionary) -> void
static func _load_finish(source: Dictionary) -> Dictionary
```

Formato v2 (lo nuevo es `acabado`):

```json
{"version": 2, "especie": "humana", "nombre": "…", "prenda_visible": true,
 "valores": {}, "colores": {"skin_color": [0.8, 0.8, 0.8], "garment_color": [0.2, 0.2, 0.23]},
 "acabado": {"mid_shade": 0.9, "rim_strength": 0.25, "rim_width": 0.3, "shadow_shade": 0.73, "softness": 0.04, "width_px": 2.5}}
```

1. `to_dict`: el parámetro nuevo va **al final y con valor por defecto**, para que las llamadas que ya existen sigan compilando. `acabado` = `BodyMaterial.finish_defaults()` con lo que traiga `finish` encima; cada número con `snappedf(…, DECIMALS)`.
2. `migrate`: como dice A4 §5.2.
3. `from_dict`: primera línea, `var migrated := migrate(data)`; si hay error, `_fail(error)`; se sigue con `migrated["data"]`. La comprobación de versión de hoy (línea 65) se quita: ya la hace `migrate`.
4. `_load_finish(source)`: empieza con `finish_defaults()`. Por cada clave de `source`: si no está en `BodyMaterial.FINISH` → error «valor de acabado desconocido 'x'»; si no es un número finito → error; si lo es, se recorta a su rango. **Una clave que falta toma su valor por defecto** (igual que en `valores`).
5. El resultado de `from_dict` gana `"acabado": {nombre: float}`.
6. `apply_look`: además de colores y prenda, `BodyMaterial.set_finish` por cada clave de `loaded["acabado"]`.

Decisión (D7): el preset guarda los 6 valores aunque el panel enseñe 4, para no tener que hacer una versión 3 cuando se añadan «tono medio» y «sombra» al panel.

### 4.7b — Panel

```gdscript
# godot/app/finish_panel.gd  (extends VBoxContainer)
signal color_changed(name: String, color: Color)      # name: "skin_color"
signal finish_changed(name: String, value: float)
signal edit_finished
const ROWS := [["softness", "Borde de la sombra"], ["rim_strength", "Luz de contorno: fuerza"],
    ["rim_width", "Luz de contorno: ancho"], ["width_px", "Grosor del contorno (px)"]]
var skin_button: ColorPickerButton
var sliders := {}        # nombre → HSlider
func setup() -> void
func show_look(colors: Dictionary, finish: Dictionary) -> void     # pone los controles sin emitir señales
```

1. `setup()`: un título «Acabado»; fila «Color de piel» con `ColorPickerButton` (`edit_alpha = false`); una fila por elemento de `ROWS` con un `HSlider` de `min_value`/`max_value` = `BodyMaterial.FINISH[nombre]` y `step = 0.01` (`width_px`: `0.1`).
2. Gesto terminado: en las barras, igual que en `slider_panel.gd` (ficha 4.4c, punto 1). En el color: `ColorPickerButton.popup_closed` → `edit_finished.emit()`.
3. `body_view.gd`: `set_color(name, color)`, `set_finish(name, value)`, `get_colors() -> Dictionary` (los dos colores) y `get_finish() -> Dictionary` (los 6), que llaman a `BodyMaterial`.
4. `body_page.gd`: el panel va en la columna derecha, debajo del de deslizadores. `get_state()` añade `"colores"` y `"acabado"`; `set_state()` los aplica y llama a `finish_panel.show_look(...)`.
5. El material es el mismo para la malla viva y la de estilo (4.6): un cambio de color se ve en las dos sin hacer nada.

### 4.7c — Guardar y abrir preset (D27)

Dos botones en el pie: «Guardar preset…» y «Abrir preset…», con `FileDialog` (filtro `*.json`), como el de exportar del 4.5.

- Guardar: `Preset.to_text(Preset.to_dict(nombre, especie, valores, colores, prenda_visible, acabado))` → `FileAccess.open(path, FileAccess.WRITE).store_string(texto)`. `nombre` = nombre del archivo sin extensión.
- Abrir: `Preset.from_text(FileAccess.get_file_as_string(path), body_view.SPECIES, species.sliders)`. Si hay error, se enseña en `status` y no cambia nada. Si no: se monta el estado, `set_state(estado)` y `history.commit(estado)` (abrir un preset se puede deshacer).

## 7. Trampas conocidas

- `probar_presets.gd` tiene hoy comprobaciones de «versión distinta de 1 → error». Con la versión 2 cambian de sentido: es cambiar una prueba. **Lista en la propuesta cada comprobación que cambias y por qué.**
- `probar_carga.gd` rechaza la «versión 2»… del **manifiesto** de `datos/` (`SpeciesData.VERSION`), que es otra versión distinta. No la toques.
- `anime.json` está en el manifiesto con su `sha256`: si lo reescribes, la especie deja de cargar. Por eso se queda en v1 (D9).
- Con `--headless`, Godot no lee los valores por defecto del shader: por eso existen `DEFAULTS` y `OUTLINE_DEFAULTS` (cabecera de `body_material.gd`).
- `JSON` lee todos los números como `float`: `2` llega como `2.0`. `migrate` debe comparar números, no tipos.
- `ColorPickerButton` emite `color_changed` muchas veces mientras se arrastra el selector: aplica el color en cada una, pero apila en el historial solo en `popup_closed`.
- El exportador ya lee el color y el grosor del material (`glb_exporter.gd:61-63`, `body_material.gd:88-99`): el `.tres` sale con el acabado elegido sin tocar nada. Añade una comprobación de eso en `probar_acabado.gd` (exportar y leer `width_px` del `.tres`).

# 4.4 — Simetría, deshacer y rehacer, y «restablecer zona»

> Paso del MVP. **Es el siguiente paso del proyecto.** Lee antes `A4_estado_y_migraciones.md`.
> Se hace en tres subpasos, cada uno con su propuesta, sus pruebas y su commit: **4.4a** núcleo, **4.4b** simetría en la interfaz, **4.4c** deshacer, rehacer y restablecer.

## 1. Objetivo y «Hecho cuando»

**Objetivo:** que los dos lados del cuerpo se muevan juntos si se quiere, que cualquier cambio se pueda deshacer y rehacer, y que una zona vuelva a sus valores de partida con un botón.

**Hecho cuando:**
- Con la simetría activada, mover «Manos › Tamaño (izq.)» mueve también la derecha, en el maniquí y en la barra.
- Al activar la simetría con lados distintos sale el aviso con la lista y tres botones; si los lados son iguales, no sale.
- Ctrl+Z y Ctrl+Y (y dos botones) deshacen y rehacen. «Igualar» y «Restablecer zona» son **un** paso de deshacer cada uno.
- `probar_historial.gd` y `probar_edicion.gd` pasan; `probar_panel.gd`, `probar_vista.gd` y `probar_ventana.gd` siguen pasando.

## 5. Diseño

### 4.4a — Núcleo

```gdscript
# godot/addons/creador/value_history.gd
class_name ValueHistory
extends RefCounted
## Historial de Deshacer por copias del estado (un Dictionary cualquiera; ver ruta/pasos/A4_estado_y_migraciones.md).
## Uso:
##   var history := ValueHistory.new(estado_inicial)
##   history.commit(estado)            # al terminar cada gesto; false si el estado no ha cambiado
##   if history.can_undo(): set_state(history.undo())

const MAX_STEPS := 100

func _init(initial: Dictionary) -> void
func commit(state: Dictionary) -> bool
func can_undo() -> bool
func can_redo() -> bool
func undo() -> Dictionary      # {} si no hay nada que deshacer
func redo() -> Dictionary      # {} si no hay nada que rehacer
func current() -> Dictionary   # copia del estado actual
static func _same(a: Variant, b: Variant) -> bool
```

Datos internos: `_states: Array[Dictionary]` y `_index: int` (posición del estado actual).

1. `_init`: `_states = [initial.duplicate(true)]`, `_index = 0`.
2. `commit(state)`: si `_same(state, _states[_index])` → `false`. Si no: `_states.resize(_index + 1)` (borra lo que se podía rehacer); `_states.append(state.duplicate(true))`; si `_states.size() > MAX_STEPS + 1` → `_states.remove_at(0)`; `_index = _states.size() - 1`; `true`.
3. `undo()`: si `_index == 0` → `{}`. Si no: `_index -= 1` y devuelve `_states[_index].duplicate(true)`.
4. `redo()`: si `_index == _states.size() - 1` → `{}`. Si no: `_index += 1` y devuelve la copia.
5. `_same(a, b)`: si `typeof(a) != typeof(b)` → `false`. Si son `Dictionary`: mismo tamaño y, para cada clave de `a`, `b` la tiene y `_same(a[clave], b[clave])`. Si son `Array`: mismo tamaño y `_same` elemento a elemento. En otro caso: `a == b`.

Decisión técnica: copias del estado y no la clase `UndoRedo` de Godot. El estado es pequeño (unos 60 números), así que copiarlo no cuesta, y «un gesto = una copia» hace triviales «Igualar» y «Restablecer zona».

```gdscript
# godot/addons/creador/shape_weights.gd — dos funciones nuevas al final
## Ids (sin _l ni _r) de los deslizadores de dos lados cuyos lados difieren más que tolerance.
static func side_differences(values: Dictionary, tolerance := 0.005) -> PackedStringArray
## Copia un lado sobre el otro en todos los deslizadores de dos lados. from_side: "_l" o "_r".
static func equalize(values: Dictionary, from_side: String) -> void
```

- `side_differences`: para cada clave que acabe en `_l`: `other := _other_side(clave)`; si `values.has(other)` y `absf(values[clave] - values[other]) > tolerance` → añade `clave.left(-2)`. Devuelve la lista ordenada.
- `equalize`: para cada clave que acabe en `from_side`: `values[_other_side(clave)] = values[clave]`.
- `0.005` es medio paso de la barra (el paso es 0,01).

### 4.4b — Simetría en la interfaz

Archivo nuevo `godot/app/body_page.gd` (`extends VBoxContainer`): la página Cuerpo entera. `main.gd` solo crea las pestañas.

```gdscript
# godot/app/body_page.gd
var body_view: SubViewportContainer
var slider_panel: ScrollContainer
var symmetry := true                       # D1: empieza activada
var symmetry_box: CheckBox
var symmetry_dialog: AcceptDialog
var pending_differences := PackedStringArray()   # lo que lista el aviso; vacío si no hay aviso abierto

func _init() -> void            # crea body_view, slider_panel y la barra (para que main.gd pueda leerlos nada más crear la página)
func _ready() -> void           # si body_view.error == "": prepara el panel y conecta las señales
func set_symmetry(on: bool) -> void
func resolve_symmetry(choice: String) -> void     # "keep", "left" o "right"
func on_value_changed(key: String, value: float) -> void
```

Disposición: arriba, una barra (`HBoxContainer`) con la casilla «Simetría»; debajo, un `HBoxContainer` con la vista (proporción 2) y el panel (como hoy en `main.gd:34-44`).

1. `main.gd`: `_body_page()` pasa a `body_page = BodyPage.new()`; `body_view = body_page.body_view`; `slider_panel = body_page.slider_panel`. Las variables `body_view` y `slider_panel` de `main.gd` **se conservan** (las pruebas las leen). Las líneas 29–31 de `main.gd` se van a `body_page._ready()`.
2. `body_view.gd`: nueva variable `var symmetry := false`; en `set_value`, `ShapeWeights.set_value(values, key, value, symmetry)`.
3. `on_value_changed(key, value)`: `body_view.set_value(key, value)`; después `slider_panel.show_values(body_view.values)` (para que la barra del otro lado se mueva).
4. `slider_panel.gd`: función nueva `show_values(values: Dictionary) -> void`: para cada clave de `sliders` que esté en `values`, `sliders[clave].set_value_no_signal(values[clave])`.
5. `set_symmetry(on)`:
   1. Si `on` es `false`: `symmetry = false`, `body_view.symmetry = false`, fin.
   2. `pending_differences = ShapeWeights.side_differences(body_view.values)`.
   3. `symmetry = true`, `body_view.symmetry = true`.
   4. Si `pending_differences` está vacío: fin (sin aviso).
   5. Si no: el texto del aviso es «Estos deslizadores tienen los lados distintos:» + un nombre por línea (columna `nombre` de la tabla, con su zona); `symmetry_dialog.popup_centered()`.
6. `symmetry_dialog` (`AcceptDialog`): título «Los lados son distintos»; `ok_button_text = "Mantener como está"`; `add_button("Igualar a la izquierda", false, "left")`; `add_button("Igualar a la derecha", false, "right")`. Señales: `confirmed` y `canceled` → `resolve_symmetry("keep")`; `custom_action` → `resolve_symmetry(action)` y `symmetry_dialog.hide()`.
7. `resolve_symmetry(choice)`:
   - `"keep"`: no cambia valores. (La simetría queda activada; cada lado se igualará cuando se mueva.)
   - `"left"`: `ShapeWeights.equalize(valores, "_l")` (el lado derecho toma el valor del izquierdo). `"right"`: al revés.
   - Con `"left"` o `"right"`: `body_view.set_values(valores)`, `slider_panel.show_values(valores)` y, desde el 4.4c, `history.commit(get_state())`.
   - Siempre: `pending_differences = PackedStringArray()`.

Significado, para que no haya dudas: **«Igualar a la izquierda» = los dos lados quedan con el valor que tenía el izquierdo.**

### 4.4c — Deshacer, rehacer y restablecer zona

```gdscript
# godot/app/body_page.gd — añadidos
const ValueHistory := preload("../addons/creador/value_history.gd")
var history   # ValueHistory
var defaults: Dictionary       # los valores del preset de personaje nuevo (D2)
var undo_button: Button
var redo_button: Button

func get_state() -> Dictionary            # {"valores": body_view.values.duplicate()}
func set_state(state: Dictionary) -> void
func on_edit_finished() -> void           # history.commit(get_state()) y actualiza los botones
func undo() -> void
func redo() -> void
func reset_zone(zone: String) -> void
```

```gdscript
# godot/app/slider_panel.gd — añadidos
signal edit_finished
signal zone_reset(zone: String)
var zone_keys := {}     # zona → Array[String] con las claves editables de esa zona
var zone_resets := {}   # zona → Button «Restablecer zona»
```

1. **Cuándo termina un gesto.** En `_add_row`: variable del panel `_dragging := false`. `slider.drag_started` → `_dragging = true`. `slider.drag_ended` → `_dragging = false` y `edit_finished.emit()`. En la función de `value_changed`: después de emitir `value_changed`, `if not _dragging: edit_finished.emit()` (teclado, o las pruebas que asignan `slider.value`).
2. **Botón «Restablecer zona».** En `_add_zone`: un `Button` con ese texto, añadido a `list` **después** de la caja de la zona (hermano de la caja, no hijo: ver §7). `open()` le pone la misma visibilidad que a la caja. Al pulsarlo: `zone_reset.emit(zone)`.
3. `reset_zone(zone)`: para cada clave de `slider_panel.zone_keys[zone]`: `valores[clave] = defaults[clave]`. Después `body_view.set_values(valores)`, `slider_panel.show_values(valores)` y `on_edit_finished()`.
4. `set_state(state)`: `body_view.set_values(state["valores"].duplicate())` y `slider_panel.show_values(body_view.values)`. No llama a `commit`.
5. `undo()`: `var state := history.undo()`; si no está vacío, `set_state(state)`; actualiza los botones. `redo()`: igual con `history.redo()`.
6. Botones «Deshacer» y «Rehacer» en la barra: `disabled = not history.can_undo()` / `not history.can_redo()`.
7. Teclado, en `body_page.gd`:
   ```gdscript
   func _unhandled_key_input(event: InputEvent) -> void:
       if event.is_action_pressed("ui_redo", false, true):   # antes que undo: Ctrl+Mayús+Z contiene Ctrl+Z
           redo()
       elif event.is_action_pressed("ui_undo", false, true):
           undo()
   ```
8. `defaults` y `history` se crean en `_ready()`, después de cargar: `defaults = body_view.values.duplicate()`; `history = ValueHistory.new(get_state())`.
9. Activar o desactivar la simetría **no** es un paso de deshacer (es un modo, no un valor).

## 7. Trampas conocidas

- **`probar_panel.gd` cambia una expectativa.** Su última comprobación (líneas 73–77) espera «mano izq. a 1: solo la izquierda». Con la simetría activada por defecto fallará. Arreglo: añadir `main.body_page.set_symmetry(false)` antes de la línea 73. No es un límite numérico, pero es cambiar una prueba: **dilo en la propuesta**.
- `probar_panel.gd:42-43` cuenta los hijos de `zone_boxes["Cabeza"]` (3) y de `Hombros` (4). Por eso el botón «Restablecer zona» **no puede ser hijo de esa caja**.
- `probar_panel.gd` y `probar_vista.gd` cargan los scripts de la interfaz desde **otro proyecto**: en `godot/app/` usa siempre `preload` con ruta relativa (`preload("body_view.gd")`), nunca `res://` ni `class_name`.
- `HSlider.set_value_no_signal()` no emite `value_changed`. Si usas `slider.value = x` dentro de `show_values`, se crea un bucle de señales.
- `AcceptDialog`: un botón de `add_button` **no cierra** el diálogo; hay que llamar a `hide()`.
- Sin ventana (`--headless`) no compruebes `symmetry_dialog.visible`: comprueba `pending_differences`.
- Los deslizadores «Por crear» no tienen clave en `values`: no entran en `zone_keys`.
- `is_action_pressed(accion, allow_echo, exact_match)`: el tercer argumento a `true` es lo que distingue Ctrl+Z de Ctrl+Mayús+Z.

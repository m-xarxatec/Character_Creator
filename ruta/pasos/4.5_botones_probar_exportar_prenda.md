# 4.5 — Botones Probar huesos, Exportar .glb y prenda base

> Paso del MVP. Depende del 4.4. Lee antes `A4_estado_y_migraciones.md` y la decisión D3.
> Dos subpasos: **4.5a** prenda y exportar; **4.5b** vista de prueba («Probar huesos»).

## 1. Objetivo y «Hecho cuando»

**Objetivo:** exportar el personaje desde la ventana, quitar o poner la prenda base, y ver el personaje **tal como se exporta** (horneado, en pose T) con el botón «Probar huesos».

**Hecho cuando:**
- «Exportar .glb» abre un diálogo de guardar y escribe `<nombre>.glb` y `<nombre>.tres`.
- La casilla «Prenda base» la muestra u oculta, y eso se respeta al exportar y al deshacer.
- «Probar huesos» cambia el maniquí por el personaje horneado en pose T (53 huesos, sin formas) y «Volver a editar» lo deshace.
- `probar_exportar_interfaz.gd` pasa; las pruebas del 4.4 siguen pasando.

La Fase 5 añadirá a esa vista las animaciones, las poses y el informe.

## 5. Diseño

### 4.5a — Prenda y exportar

```gdscript
# godot/app/body_view.gd
func set_garment_visible(on: bool) -> void     # BodyMaterial.set_garment_visible(species.mesh, on)
func is_garment_visible() -> bool
## Exporta el personaje en pose T (regla de CLAUDE.md hasta el paso 5.5). Devuelve OK o el error.
func export_glb(path: String) -> Error
```

```gdscript
# godot/app/body_page.gd
var garment_box: CheckBox
var export_button: Button
var export_dialog: FileDialog
var status: Label                # una línea de estado debajo de la vista
func export_to(path: String) -> Error
```

1. Casilla «Prenda base» en la barra, marcada según `body_view.is_garment_visible()`. Al cambiar: `body_view.set_garment_visible(on)` y `on_edit_finished()`.
2. **Estado:** `get_state()` añade `"prenda_visible": body_view.is_garment_visible()`; `set_state()` lo aplica con `state.get("prenda_visible", true)` y actualiza la casilla con `set_pressed_no_signal`.
3. `body_view.export_glb(path)`: `return GlbExporter.save(species.mesh, species.skeleton, species.manifest["bones"]["sockets"], path, true)`.
4. Pie de la página (como en la maqueta): botones «Probar huesos» y «Exportar .glb».
5. `export_dialog`: `file_mode = FileDialog.FILE_MODE_SAVE_FILE`, `access = FileDialog.ACCESS_FILESYSTEM`, `filters = PackedStringArray(["*.glb ; Personaje (glTF binario)"])`, `use_native_dialog = true`. Señal `file_selected` → `export_to`.
6. `export_to(path)`:
   1. Si `path` no acaba en `.glb` (sin distinguir mayúsculas), se añade.
   2. `status.text = "Exportando…"`; `await get_tree().process_frame` dos veces (para que el texto llegue a pintarse; la exportación bloquea unos 1,5 s por la textura de la prenda).
   3. `var error := body_view.export_glb(path)`.
   4. `status.text = "Guardado: " + path` si `error == OK`; si no, `"No se pudo exportar (error %d). ¿Tienes permiso para escribir en esa carpeta?" % error`.
   5. Devuelve `error`.

### 4.5b — Vista de prueba

Cambio en el núcleo (A5 de `ARQUITECTURA.md` §9):

```gdscript
# godot/addons/creador/glb_exporter.gd
## with_texture = false: sin material ni textura horneada (quien llama pone el material). Para la vista de prueba del editor.
static func build(mesh: MeshInstance3D, skeleton: Skeleton3D, socket_names: Array, t_pose: bool, with_texture := true) -> Node3D
```

Dentro de `build`: `_garment_in_alpha` se llama siempre; `_material` y `surface_set_material` solo si `with_texture`. `save()` no cambia (usa el valor por defecto).

```gdscript
# godot/app/body_view.gd
var preview: Node3D            # el personaje horneado, o null
var preview_ms := 0
## true: construye el personaje horneado en pose T y lo enseña en lugar del maniquí. false: lo libera y vuelve el maniquí.
func show_preview(on: bool) -> bool      # false si no se pudo construir
```

1. `show_preview(true)`:
   1. Si ya hay `preview`, se libera primero.
   2. `preview = GlbExporter.build(species.mesh, species.skeleton, species.manifest["bones"]["sockets"], true, false)`. Si es `null` → `false`.
   3. Su malla: `preview.find_children("*", "MeshInstance3D", true, false)[0]`; se le pone `material_override = species.mesh.material_override` (el **mismo** material: mismo color, misma prenda, mismo contorno).
   4. Se añade `preview` al mismo padre que `species.scene`; `species.scene.visible = false`.
   5. Se mide el tiempo en `preview_ms`.
2. `show_preview(false)`: `preview.queue_free()`, `preview = null`, `species.scene.visible = true`.
3. En `body_page`: «Probar huesos» es un botón de dos estados (`toggle_mode = true`); pulsado, su texto es «Volver a editar». Con la vista de prueba activa: `slider_panel.visible = false` y `status.text = "Vista de prueba: así se exporta el personaje."`.
4. `set_state()` y `undo()` con la vista de prueba activa: primero `show_preview(false)` y se suelta el botón.

Decisión técnica (D3): la vista de prueba usa `GlbExporter.build`, el mismo camino que el archivo. Lo que se ve es lo que se exporta.

## 7. Trampas conocidas

- `GlbExporter.build` devuelve un nodo **sin padre**: quien lo recibe lo libera (`queue_free()` si está en el árbol, `free()` si no).
- El personaje de `build` aún no tiene el nodo `Armature` (lo añade `save`): en la vista previa, el esqueleto es el primer hijo de la raíz.
- En el `.glb`, el color `garment` va en el alfa y el RGB es blanco; `toon.gdshader:26` ya lo entiende (`min(COLOR.r, COLOR.a)`): el material del editor sirve tal cual.
- `user://` en las pruebas es el del proyecto `pruebas/godot`. Borra `user://prueba_interfaz/` al terminar.
- `use_native_dialog` necesita un sistema con diálogo nativo; sin ventana no se abre nada: la prueba llama a `export_to` directamente.
- La exportación tarda (1,5 s medidos en el 3.6.6). No la lances en cada fotograma ni en cada cambio.
- En el personaje vivo los anclajes son huesos; en la vista previa, nodos. No mezcles las dos cosas.

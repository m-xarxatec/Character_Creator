# 8.3 — Guardar y abrir archivos en Windows

> Fase 8. Depende de 4.5 (exportar desde la interfaz), 4.7 (presets desde la interfaz, si D27 = a) y 8.2.

## 1. Objetivo y «Hecho cuando»

**Objetivo:** que exportar y guardar funcionen en las rutas reales de un Windows: con espacios, con tildes, largas y sin permiso.

**Hecho cuando:**
- `probar_rutas.gd` pasa en Linux y en Windows.
- Si no se puede escribir, el usuario ve un mensaje con la ruta y el motivo. Nunca un fallo en silencio ni un archivo a medias.

## 2. Nivel de modelo

**Medio.** Hay que decidir dónde se captura cada error sin meter interfaz en el núcleo.

## 5. Diseño

```gdscript
# godot/app/file_paths.gd
## Ayudas de rutas para guardar y exportar. Sin nodos: se prueba sin ventana.

## Carpeta inicial del diálogo: la última usada si existe; si no, Documentos; si no, user://.
static func start_folder(last_used: String) -> String

## Limpia un nombre de archivo propuesto por el usuario: quita \ / : * ? " < > | y los espacios y puntos finales;
## si queda vacío o es un nombre reservado de Windows (CON, PRN, AUX, NUL, COM1–9, LPT1–9), devuelve "personaje".
static func safe_name(text: String) -> String

## Comprueba ANTES de exportar que se puede escribir en la carpeta. Devuelve "" si se puede, o el mensaje para el usuario.
static func write_problem(path: String) -> String
```

Algoritmos:

1. `start_folder`: si `DirAccess.dir_exists_absolute(last_used)` → esa. Si no, `OS.get_system_dir(OS.SYSTEM_DIR_DOCUMENTS)` si existe. Si no, `OS.get_user_data_dir()`.
2. `safe_name`: recorrer los caracteres y quitar los prohibidos; `strip_edges()`; quitar puntos finales; comparar en mayúsculas con la lista de reservados. Se aplica igual en Linux, para que un proyecto guardado en Linux se pueda copiar a Windows.
3. `write_problem(path)`:
   1. Si `path.length() > 240` → «La ruta es demasiado larga para Windows (más de 240 caracteres). Elige una carpeta más corta.» (Margen sobre el límite clásico de 260.)
   2. Si la carpeta no existe → «La carpeta no existe: …».
   3. Intentar crear `<carpeta>/.gamemolde_prueba.tmp` con `FileAccess.open(…, WRITE)`. Si falla → «No se puede escribir en …» + `error_string(FileAccess.get_open_error())`. Si funciona, cerrar y borrar con `DirAccess.remove_absolute`.
   4. Devolver `""`.
4. **En la interfaz**, al aceptar el diálogo: `safe_name` sobre el nombre → `write_problem` → si hay mensaje, mostrarlo en un `AcceptDialog` y no exportar → si no, `GlbExporter.save(...)` → si devuelve algo distinto de `OK`, mostrar `error_string(err)` y la ruta → si `OK`, comprobar que existen **los dos** archivos (`.glb` y `.tres`) y mostrar «Guardado en …».
5. **Diálogo del sistema:** `file_dialog.use_native_dialog = true` y `access = FileDialog.ACCESS_FILESYSTEM`. Filtros: `*.glb ; Personaje para juegos`. Si el diálogo nativo no está disponible, Godot usa el suyo: no hay que hacer nada.
6. **Sobrescribir:** el diálogo ya pregunta si el `.glb` existe. El `.tres` de al lado se sobrescribe sin preguntar: es su pareja. Decirlo en el mensaje «Guardado en …».

## 6. Prueba

`pruebas/godot/probar_rutas.gd` (sin ventana). Trabaja dentro de `user://prueba_rutas/` y lo borra al terminar.

| Caso | Se espera |
| --- | --- |
| Exportar a `…/Mi carpeta/José Pérez ñ/héroe.glb` | `OK`; existen `.glb` y `.tres`; `probar_glb` sobre el resultado pasa |
| Exportar a una carpeta con caracteres no latinos (`…/テスト/`) | `OK` |
| `safe_name("a<b>:c?.glb")` | `"abc.glb"` |
| `safe_name("CON")`, `safe_name("  ")`, `safe_name("nombre. ")` | `"personaje"`, `"personaje"`, `"nombre"` |
| `write_problem` con una ruta de 300 caracteres | Mensaje de ruta larga |
| `write_problem` con una carpeta que no existe | Mensaje de carpeta inexistente |
| `write_problem` con una carpeta de solo lectura (solo Linux: `chmod 555`; en Windows se salta e imprime `SALTADA`) | Mensaje «No se puede escribir» |
| Tras un `write_problem` correcto, no queda `.gamemolde_prueba.tmp` | 0 archivos |
| `start_folder("/no/existe")` | Devuelve una carpeta que existe |

**Que la prueba detecta el fallo:** hacer que `safe_name` devuelva el texto sin cambiar → fallan 2 casos. Hacer que `write_problem` devuelva siempre `""` → fallan 3.

Prueba manual en Windows (el responsable, 5 minutos): exportar al Escritorio; exportar a `C:\Program Files\` (debe salir el mensaje, no un cuelgue); exportar a una carpeta de OneDrive si la hay.

## 7. Trampas conocidas

- Godot devuelve y acepta rutas con `/` también en Windows. No conviertas a `\`: `path_join` y `get_base_dir` funcionan con `/`.
- `OS.get_system_dir(OS.SYSTEM_DIR_DOCUMENTS)` en Windows puede apuntar a una carpeta de OneDrive: es correcto.
- Que Godot admita rutas de más de 260 caracteres en Windows depende de la versión de Windows y del manifiesto del `.exe` (**NO VERIFICADO**). Por eso se avisa a partir de 240 en vez de intentarlo.
- Windows no distingue mayúsculas en nombres: `Heroe.glb` y `heroe.glb` son el mismo archivo. No hay nada que arreglar; solo no escribir pruebas que cuenten con dos archivos así.
- El diálogo nativo en `--headless` no se abre: la prueba no lo usa; prueba solo las funciones.
- `file_paths.gd` es de la interfaz (`app/`). El núcleo sigue devolviendo `Error`, sin textos para el usuario.

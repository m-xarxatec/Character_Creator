# Referencias de inspiración

Imágenes de lo que me gustaría conseguir. Solo inspiración: no se copian.

## Reglas

- Solo **dibujos míos**, imágenes **CC0** o imágenes **con permiso escrito** del autor.
- Las imágenes con derechos de autor van **solo en local**, en `privadas/` (git no la guarda; ver `.gitignore`).
- **Nada de VRoid:** ni mallas, ni texturas, ni capturas.
- Las de terceros que sí van en git se apuntan también en `CREDITOS.md`.

## Nombre

`<tema>_<autor-o-fuente>_<nn>.png`, por ejemplo `cara_propio_01.png` o `chibi_cc0-openclipart_02.png`.
